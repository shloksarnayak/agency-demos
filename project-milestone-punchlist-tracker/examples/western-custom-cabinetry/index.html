A $50,000 custom cabinetry order shouldn't be tracked by memory and email

Western Custom Cabinetry's own site (westerncustomcabinetry.com) has one path in for any project: a "Schedule Consultation" contact form. After that, everything, measuring, ordering, production, shipping, delivery, install and punch-list, is coordinated by phone and email, with no client-facing way to see where a project actually stands. A public BBB complaint on file (filed 10/24/2025) shows exactly this gap in practice: the owner personally coordinating a remeasure and reshipment by hand over email, with no structured record of what was open or closed. Below is a working tool sized to close that gap: every order gets a shared milestone ticket the whole team can see, punch-list items are logged individually and stay open until someone closes them with a note, and the client can check both without a phone call.

How this gets built for real

The order number is whatever Western already uses. A real build reads from the existing project or contract number instead of inventing a new one for the client to remember.
Punch-list items here are logged by staff on the spot. A real build can also let the client flag a punch-list item themselves after the install walkthrough, still landing in the same shared, closeable list, instead of an email that can get lost for months.
This does not replace the design team's judgment. It only makes a stalled measure, a delayed shipment, or an open punch-list item visible to the whole team automatically, instead of surfacing only when a client calls to ask.
