How this gets built for real

The drawing is a schematic, not a CAD elevation. It's a to-scale-ish plan diagram built from the same footage numbers already on the estimate, enough to hand to a customer as the “detailed drawing” already promised, not a replacement for a full design drawing on a complex roofline.
“Sent” here means generated and ready to email. A real build wires this into the business's actual outbound email at (239) 482-1186's Lee County office and the (239) 513-1175 Collier County line's intake flow, this demo only shows the document and the status change.
Follow-up tracking targets the ten-calls-no-callback pattern directly. Any estimate untouched for 5 days surfaces as needing follow-up on the status board, so a repeat caller doesn't go three months without a return call.
