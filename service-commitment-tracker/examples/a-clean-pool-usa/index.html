Every route stop leaves proof it actually happened, before the invoice goes out

A Clean Pool USA runs routes across 60-plus Central Florida zip codes (Orlando, Winter Park, Lake Nona, Dr. Phillips, Kissimmee, Seminole and Volusia County). With that many stops a week, a handful of public reviews describe a visit that was billed as completed while the homeowner wasn't sure the technician actually came that week. This page shows one small, working tool aimed at that exact gap: a technician confirms a short checklist (and optionally a photo) at each stop, anything incomplete gets flagged for the office before it's invoiced, and the homeowner can look up their own stop and see proof it happened, without calling the office.

How this gets built for real

The checklist matches the actual service plan. A real build sets the items to whatever A Clean Pool USA's technicians already do per visit, not this demo's five defaults, and can vary by plan tier (e.g. photo required on premium routes only).
The notification is real, not a page you have to load. In production this sends an automatic text or email the moment a stop is marked complete, with the checklist summary and photo attached, so the homeowner never has to check a page unless they want more detail.
It sits alongside the existing route app, it doesn't replace it. This plugs into however routes are dispatched today and only adds the completion check, the office flag, and the customer-facing confirmation on top.
The reference code is whatever the office already uses. A real build ties this to the existing work-order or account number instead of a new code for the customer to remember.
