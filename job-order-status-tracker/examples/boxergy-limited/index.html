Right now, checking on an installation means calling and hoping someone picks up

At least six separate Trustpilot reviewers between June 2025 and February 2026 describe the same gap: an install books in, then goes quiet for weeks with no proactive update, and the only way to find out what's happening is to keep calling or emailing. Ben Cutler-Ames (1-star, Dec 2025) wrote that dates slipped "without explanation" and he had "repeatedly had to chase for basic updates." Christopher Kelly (2-star, Feb 2026) said "80% of the time, no one answers the phone," and messages went unanswered. JW (2-star, Oct 2025) and S Wood (2-star, Feb 2026) both describe the same pattern of having to chase for any word. Two otherwise 5-star reviews still flag "communication and paperwork delays." I checked boxergy.co.uk directly: there is no customer-facing status page, tracker, or login anywhere on the site. Below is a working tool sized to close that specific gap, not the whole business: a customer enters a reference code and sees exactly where their install stands, and the office gets one shared queue instead of a phone line everyone is chasing.

What I'd flag before this goes further

The six stages shown (survey booked, quote issued, grant/funding confirmed, install scheduled, installed, commissioning signed off) are a typical heat pump/solar/battery/EV-charger installer workflow, not copied from Boxergy's own internal process. Boxergy's real stage names, and whether grant/funding (e.g. a scheme like the Boiler Upgrade Scheme) applies to a given job, would take a short conversation to confirm before this gets built for real.
The reference code here is invented for this demo. A real build reads from whatever job or quote number Boxergy already hands out, rather than inventing a new one for the customer to remember.
The status update here is a log entry, not a real send. A real build wires this to Boxergy's existing email or phone system so the update actually reaches the customer the moment a stage changes, which is the exact gap the reviews above describe.
This doesn't fix a genuinely delayed install. It means the customer and the office both see where a job stands before it becomes six weeks of unanswered calls, same as every other case in this template family.
