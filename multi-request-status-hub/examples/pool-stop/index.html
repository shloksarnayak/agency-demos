Client example, built from public information

One status view for a pool build or a leak/repair ticket, no call needed

Pool Stop, Inc., a custom inground pool and backyard-living builder in Rockwall, Texas, has operated under the same legally registered entity for 22 years, holds a live, renewed USPTO trademark on "POOL STOP," and was profiled in Aqua Magazine's 2019 "Aqua 100" list of top US pool builders. The large majority of its 228+ aggregated reviews are genuinely positive, often naming individual project managers for proactively keeping customers updated. A real but narrower pattern sits alongside that: a recent review and several 2023-2025 BBB complaints describe the opposite experience on both new builds and post-build repairs, including a customer left functioning as the project's own de facto site manager, leak-retest results requested but never shared, and repair technicians who stop reporting back mid-case. Pool Stop's own 2024 BBB response confirms it already runs an internal project-management tool for customer messaging, so the gap is not "no process" but that the customer's own view of status does not hold up when a given project manager is not proactive that week. This example shows a small, working alternative: a status page a customer can check themselves, for either an active build or an open repair/retest item, independent of which project manager happens to be assigned.

How this gets built for real

The reference number is generated the moment a build contract is signed or a repair/retest issue is reported. A real build hands it to the customer immediately, the same way Pool Stop already reaches customers today.
The build-phase sequence here is a typical custom inground pool build, not copied from Pool Stop's own internal workflow. A real build matches whatever phases Pool Stop's own crews actually use, sized to a multi-month project rather than a same-day service call.
The "next crew/technician visit" field is the direct answer to the specific complaint pattern: a customer reduced to functioning as their own site manager. It stays visible and up to date even when the build phase itself has not changed yet, and it carries its own notification whenever a visit date is set or moved.
The attention flag is sized to a multi-month build (roughly 10-14 days with no change here), not a same-day job. It exists to catch exactly the "leak-retest results requested but never shared" and "technician stopped reporting back" pattern described in the BBB complaints, regardless of which project manager is assigned that week.
The status update here is a log entry, not a real send. A real build wires this into whatever phone, text or email channel Pool Stop's existing internal project-management tool already uses, rather than adding a second system.
This tracks build-phase and repair/retest visibility only. The review record this is grounded in shows a strongly positive majority (4.2-4.3 average across 228+ reviews); this tool does not claim to fix staff conduct, change pricing, or replace the internal tool Pool Stop already runs, only whether a customer can see where their build or repair stands without calling.
