Working examples

Small working prototypes, each built to show one real automation solving one real problem for one real business. The library grows over time — even for businesses that never wrote back.

Notice: every prototype here is illustrative, uses sample or publicly available data only, and is not affiliated with or endorsed by the businesses referenced.
  • Product-finder quiz
    A few quick questions, answered against a retailer's own published guides, ending in one real in-stock recommendation. Built for Ministry of Sight.
  • Support-ticket triage & drafting
    Sample tickets sorted by urgency, with drafted replies and a clock deciding what needs a human. Built for Jewelry Candles.
  • Instant quote calculator
    Turns a business's own published pricing and travel-zone table into a live, self-serve quote. Built for Pool Table Guy.
  • Review showcase widget
    Pulls scattered third-party praise into one filterable display on a business's own site. Built for George's Concrete Pumping.
  • Appointment request widget
    Catches the after-hours visitor who's comparing options online, before they book with a competitor instead. Built for Wohl Optics.
  • Order & job status lookup
    A self-serve status check for a repair, order, or build, so customers stop having to call to find out where things stand. Built for S&S Appliance.
