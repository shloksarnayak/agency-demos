Match a messy order to your catalog, and flag what it isn't sure about

Distributors get purchase orders with the buyer's own part numbers, a typo, or a vague description instead of a real SKU. Someone on staff has to figure out what each line actually is, by hand, before it can be priced and keyed in. This page uses a fictional catalog to show what a first pass looks like, matched, flagged for review, or marked as not carried, never guessed and never auto-finalized.

Everything below is fictional. The catalog and the sample orders are made up for this template. When this gets built for a real distributor, it reads their actual catalog export or product feed, the way the example below does with a real supplier's real public pricing.

How this gets built for real

A real catalog, not this fictional one. A real build reads whatever export or feed the distributor already keeps current, all of it, not a hand-picked slice.
It never places or finalizes an order. Every line either gets a person's yes or gets flagged for one. This produces a clean draft for staff to key in, not a submitted order.
