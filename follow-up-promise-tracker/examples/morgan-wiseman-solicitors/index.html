Morgan Wiseman Solicitors: give every open matter a next-action deadline the office can see is overdue before a client has to chase it

Three independently dated Trustpilot reviewers across roughly a 10-month span describe the same pattern once a matter opens, particularly in family law and domestic abuse cases: no proactive update, calls and emails that go unanswered, and urgent court deadlines that slip. One reviewer says a solicitor attended the wrong court for a non-molestation order hearing while calls went unanswered, leaving them unrepresented. Another says a formal complaint to a supervisor about an unsubmitted urgent application went unanswered. This reviewer pattern is corroborated by the Legal Ombudsman's own public decision register, which records one upheld "Poor Service" finding against this firm for "Failure to provide advice" (reference D012305, Family Law), with compensation ordered. The firm's own site has no client-facing case-status page of any kind today, only a contact form. Below is a small working tool sized to close exactly that gap: every open matter gets a next-action-due date and, where one applies, a filing deadline, both visible to the office before either one is missed, and a client can check status by reference code without depending on reaching one specific person by phone.

How this gets built for real

A filing deadline is attached to the matter, not to one fee-earner's memory. The non-molestation order review describes a missed court hearing after attending the wrong court; a real build keeps the deadline on the matter record itself, flagged automatically as it approaches, rather than depending on one person remembering it.
A matter stays visible between hearings or filings, not just at intake. The "urgent application still not submitted weeks after first contact" pattern in the reviews happens when a case is treated as handled after the first instruction; a real build keeps the next-action date open until the firm actually acts.
Overdue next-actions and filing deadlines surface to the office automatically, before a client calls or emails twice, or a hearing is missed. This is where a real build would flag the assigned fee-earner, or a supervisor if a formal complaint has already been raised, instead of relying on someone opening this page.
The reference code is whatever the firm's own matter number already is. A real build reads from an existing file or matter reference instead of asking a client to remember a new code.
The client view shows only client-safe wording. Internal notes typed in the office view never appear on the lookup page.
