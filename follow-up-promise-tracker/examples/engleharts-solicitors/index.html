Engleharts Solicitors: give every open matter, and every complaint about one, a next-contact date the office can see is overdue

Five independently dated Trustpilot reviewers across the last 12 months describe the same pattern across conveyancing and wills/probate matters: calls, emails, and even in-person visits go unanswered until the client is forced to chase repeatedly. One reviewer describes being ignored for nine months by the Client Care Manager, then having a formal complaint to the Senior Partner go unanswered too. This reviewer pattern is corroborated by the Legal Ombudsman's own public decision register, which records one upheld finding against this firm for poor complaints handling in a Wills and Probate matter (reference D012215, decided 27/01/2026, compensation ordered). Disclosed rather than hidden: a separate Google-review aggregation shows a more positive 4.4/5 from 211 reviews, so the picture is genuinely mixed, not one-sided. The firm's own site has no client-facing case-status page of any kind today, only an enquiry form and a client survey link. Below is a small working tool sized to close exactly that gap: every open matter, and every open complaint about one, gets a next-contact-due date the office can see is overdue before a client has to chase it twice, and a client can check status by reference code without depending on reaching one specific person.

How this gets built for real

A complaint gets the same next-contact date as a live matter. The reviewer whose formal complaint to the Senior Partner went unanswered, and the Legal Ombudsman's own upheld finding on poor complaints handling, both describe a complaint being treated as a dead end rather than a tracked item with its own due date; a real build puts complaints in the same overdue queue as any other open matter.
A matter stays visible between milestones, not just at intake. The "months with no update" pattern in the reviews happens once a file is opened and then goes quiet; a real build keeps the next-contact date open until the firm actually makes contact again.
Overdue next-contacts surface to the office automatically, before a client calls, emails, or visits in person a second time. Once a due date passes, this is where a real build would flag whoever the matter or complaint is assigned to, instead of relying on someone opening this page.
The reference code is whatever the firm's own matter or complaint number already is. A real build reads from an existing file reference instead of asking a client to remember a new code.
The client view shows only client-safe wording. Internal notes typed in the office view never appear on the lookup page.
