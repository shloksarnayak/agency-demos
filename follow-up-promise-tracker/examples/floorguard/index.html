Every promised callback gets a due date, and every finished job gets a written scope both sides can point to

Floorguard's own BBB complaint file shows the same shape three separate times behind an otherwise strong 36-year reputation: a real, undisputed defect or add-on request comes in, the company does not deny it, and then a promised callback, inspection, or repair visit is dropped for months with no update until the customer files a formal complaint. A separate case, found independently on HomeAdvisor, shows a related gap: a job stopped mid-way over a square-footage threshold dispute that was never confirmed in writing with the customer. This page shows two small tools that close both gaps: a warranty and callback queue that surfaces anything overdue, and a written scope confirmation captured before the crew leaves the last visit.

Job scope confirmation, captured before the crew leaves

The HomeAdvisor complaint describes a job stopped mid-way because the crew believed two rooms exceeded a 400 sq ft contract threshold, a figure the customer's own remeasurement disputed after the fact. This tool captures the measured square footage, any add-on, and any explicitly excluded area in writing, with the customer's name attached, at the end of the visit, so a dispute like that one has a shared reference point instead of two memories.

How this gets built for real

The reference code can be whatever the office already writes down. A real build reads from an existing job or work-order number instead of asking a customer to remember a new code.
This does not replace the existing quote-request form. The warranty queue and scope confirmation sit on top of however jobs already get scheduled and quoted through floorguard.com's own form.
The customer view shows only customer-safe wording. Internal notes typed in the office view never appear on the lookup page.
"Confirmed" here is a typed name and a timestamp. A real build can use an e-signature provider or a crew-lead's tablet signature capture if Floorguard wants a stronger legal record; this demo shows the workflow, not a specific vendor.
